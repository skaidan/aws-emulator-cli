# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks aren't welcome in issues, pull requests, discussions or anywhere else the project is represented.

To report unacceptable behaviour, write to the maintainer privately (the contact on [@skaidan](https://github.com/skaidan)'s GitHub profile) or use [Report a vulnerability](https://github.com/skaidan/aws-emulator-cli/security/advisories/new) if it needs to stay private. Reports are handled confidentially, and the maintainer may remove content or block people who don't follow these rules, as the Covenant's enforcement guidelines describe.
